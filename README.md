# समर्थ्य-STAT (Samarthya-Stat)

**AI-Enabled Skill Intelligence and Learning Platform for India's Official Statistical System.**

Samarthya-STAT is a React + Vite prototype for competency assessment, skill-gap analysis and personalized learning workflows. The supplied project includes learner and admin views, competency assessment, skill-gap analysis, personalized recommendations, document-based quiz generation UI, an AI chatbot UI, learner profiles and an administrative dashboard.

## Tech Stack

- React 19
- Vite
- JavaScript / JSX
- CSS
- Tailwind CSS
- Lucide React
- Recharts
- Canvas Confetti
- Oxlint

## Main Features

- Login / registration flow
- Learner profile and competency scores
- Competency assessment
- Skill-gap analysis
- Personalized learning recommendations
- Document quiz generator UI
- Continuous learning loop
- AI chatbot UI
- Admin dashboard
- Sample/mock learner and resume data

## Run Locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
